# Security Policy

## Reporting a Vulnerability

If you discover a vulnerability **in the toolkit itself** (not a target), please report it responsibly:

1. **Do NOT** open a public issue
2. Email: [create a private security advisory](https://github.com/GSHINE2002/hack-skill/security/advisories/new)
3. Include: description, reproduction steps, impact assessment

You will receive a response within 72 hours.

## Responsible Use

This toolkit is designed for **authorized security testing only**. Users are solely responsible for:

- Obtaining proper authorization before testing any target
- Compliance with all applicable laws and regulations
- Ethical use of all testing capabilities

The toolkit includes **no authorization verification mechanism** by design. This is not an endorsement of unauthorized testing — it is an acknowledgment that authorization assessment is the user's responsibility, not the tool's.

## Scope

This security policy covers vulnerabilities in the **toolkit's code itself**, not:
- Vulnerabilities discovered in targets being tested
- Issues arising from misuse of the toolkit
- Third-party tool integrations (ZAP, Nuclei, etc.)
